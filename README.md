#  Data Anonymization Web App

Une **application web** innovante conçue pour **anonymiser des datasets** et protéger les données sensibles, tout en facilitant leur traitement et leur analyse. 
Ce projet vise à fournir une solution sécurisée et simple pour manipuler des données personnelles en conformité avec les standards de confidentialité (RGPD).

---


## Fonctionnalités principales

### Interface Utilisateur
- Upload de datasets (CSV)  
-  Anonymisation simple et rapide des données personnelles  
-  Export des datasets anonymisés  
-  Visualisation des données après anonymisation  

###  Interface Admin
-  Upload de datasets (CSV) 
-  Gestion des utilisateurs et permissions  
-  Suivi et gestion des datasets traités  
-  Paramétrage avancé des techniques d’anonymisation  
-  contrôle d’accès 

## Technologies utilisées
- **Frontend** : React 
- **Backend** : Flask
- **Librairies** : Pandas, Numpy pour le traitement des données  
- **Outils** : Git, GitHub, VS Code
